간단한 달력 사이트  

구글로 로그인이 가능하면 본인만의 일정을 기록할 수 있음.  
링크 복사로 자신만의 개인 일정을 공유도 가능함.  

로그인하면 본인의 별칭을 정해서 누구의 일정인지 알 수 있음.  
기본 출시 일정은 관리자 UID를 정해주어야 그 관리자가 추가와 편집이 가능함.  
  
3년 이후의 일정은 백업하고 지우도록 변경함.  
그냥 백업은 지우지 않음. 다만 아직 백업을 다시 복구하는 기능을 넣지 않았음.
